ΠΡΩΤΗ ΕΝΕΡΓΟΠΟΙΗΣΗ
1. Ανεβάστε όλα τα περιεχόμενα του φακέλου σε κανονικό web hosting (HTTPS).
2. Κάντε μία δοκιμαστική υποβολή από τη φόρμα επικοινωνίας.
3. Ελέγξτε το inbox του bstratakis@yahoo.gr (και τα Spam/Junk) για email επιβεβαίωσης από το Formspree, εφόσον ζητηθεί.
4. Πατήστε τον σύνδεσμο επιβεβαίωσης. Η αρχική επιβεβαίωση απαιτείται από το Formspree πριν παραδίδονται κανονικά τα αιτήματα.
5. Δοκιμάστε και τη φόρμα αξιολογήσεων. Οι αξιολογήσεις αποστέλλονται για έλεγχο και δεν δημοσιεύονται αυτόματα.
